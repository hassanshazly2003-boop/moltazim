# ملتزم v4

نسخة مطورة من مشروع ملتزم.

## ما تم إضافته
- مصحف عربي Offline كامل داخل assets/quran/quran.json.
- فهرس السور الـ114.
- بحث داخل نص القرآن بدون إنترنت.
- حفظ آخر سورة وآية وصل إليها المستخدم.
- الورد: صفحات / سورة / جزء، مع زر يفتح الموضع مباشرة في المصحف.
- الصلوات الخمس مع مواقيت محسوبة على الجهاز واختيار مدينة مصرية.
- أذكار الصباح والمساء مع حفظ التقدم والنقاط.
- الاستمرارية والأوسمة والنقاط.
- شعار التطبيق الموجود في النسخة السابقة.

## مصدر النص
تم تضمين ملف المصدر الأصلي `assets/quran/qurantext-uthmani.source.def` مع بيانات JSON المشتقة منه، مع ملف الترخيص.

يوجد أيضًا `tool/build_quran_assets.py` لإعادة بناء بيانات JSON من ملف Tanzil-style `quran-uthmani.txt` دون تغيير نص الآيات.

## ملاحظة مهمة
مواقيت الصلاة الحالية Offline وتسمح باختيار المدينة. تحديد GPS تلقائيًا يحتاج إضافة صلاحيات الموقع وplugin مثل geolocator في مشروع Android النهائي.

الدفع الحقيقي وBackend وVIP online لم يتم تفعيلها في هذه النسخة بعد.
